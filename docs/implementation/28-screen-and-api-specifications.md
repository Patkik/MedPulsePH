## 2. API & State-Transition Contract Rules

- **Default-Deny Routing:** Keep unfinished HTTP routes disabled (`404 Not Found`) until their authentication, capability, schema validation, and durable audit gates are implemented (`backend/src/lib.rs`).
- **Optimistic Concurrency & Idempotency:** Every mutating clinical or band operation requires `ResourceVersion` (`ETag` / `If-Match`) and a `ScopedIdempotencyRecord` (`backend/src/vault.rs`) bound to `(actor_id, hospital_id, operation, idempotency_key, payload_sha256)`.
- **Skill Synchronization:** Update affected `.agents/skills` and `.claude/skills` mirrors alongside any screen, permission, or API contract change and verify with `node scripts/check-skill-sync.mjs`.
